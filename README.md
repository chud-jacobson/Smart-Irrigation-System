# IoT-Irrigation-System
## Main Components:
<ul>
  <li> <b>Microcontroller</b>: ESP32-C6 SuperMini</li>
  <li> <b>Server</b>: Raspberry Pi 5, 4GB RAM</li>
  <li> <b>Sensor</b>: Capacitive Soil Moisture Sensor </li>
  <li> <b>Motor Controller</b>: PWM MOSFET 15A</li>
  <li> <b>DC-DC Step-down Converter</b>: 9V-12V-24V-36V ---> 5V-3A</li>
  <li> <b>Mini Water Pump</b>: 365DC 12V</li>
  <li> <b>Power Supply</b>: 12V-3A Sony Adapters</li>
</ul>
